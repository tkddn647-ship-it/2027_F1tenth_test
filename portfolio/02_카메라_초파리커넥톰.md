> LiDAR·지도·위치추정 없이 **depth 카메라(Orbbec Gemini 2L) 한 대**가 본 것을 **초파리 시각계를 본뜬 회로**에 넣어 바로 조향·속도를 낸다.

## 1. 왜 이렇게 했나

**왜 카메라:** LiDAR 정책([01](01_라이다_강화학습.md))은 잘 달리지만, 카메라가 더 싸고 멀리 보며 대회도 허용한다.
**왜 RGB 가 아니라 depth:** 트랙 경계(에어덕트)와 장애물 색이 정해져 있지 않다. RGB 는 색·조명을 전부 랜덤화해서 배워야 하지만
depth 는 거리만 재므로 색과 무관하고, 카메라 칩이 계산해서 Jetson 부담도 거의 없다.

**왜 초파리 커넥톰:**

| 이유 | 내용 |
|--|--|
| 하는 일이 같다 | 초파리 시각계는 빠르게 날며 벽·장애물을 피하고 코스를 유지하도록 진화했다. 회전·흐름 감지(HS), 다가오는 물체 감지(LPLC2) 같은 회로가 이미 있다 |
| 작고 빠르다 | 학습 값 약 760개 (LiDAR 정책은 10만 개 이상). Jetson CPU 에서 프레임당 수 ms, GPU 불필요 |
| 시뮬→실차에 유리할 것으로 기대 | 연결 구조는 고정, 연결 세기만 학습 → 시뮬의 사소한 특징에 덜 맞춰질 것 (검증 필요) |
| 들여다볼 수 있다 | 어느 뉴런이 왜 켜져서 왼쪽으로 꺾었는지 볼 수 있다 |

*실제 초파리 연결 데이터가 아니라, 알려진 세포 유형·연결 원칙(좌우 대칭, 같은 쪽 흥분/반대쪽 억제 등)을 따른 **합성 회로**다.*

## 2. 구조

```
Gemini 2L depth (30 fps)
  → 파리 눈 격자 16×64 '가까움' = 0.25 m / 거리   (바닥 제거, 정면 ±15° 와 지평선 ±8° 에 칸을 몰아줌)   × 최근 3프레임
  → lamina    ON/OFF 시간 변화 + 대비 적응
  → T4/T5     움직임 방향 검출 (좌·우·상·하)
  → HS/VS     좌우·상하 흐름 · LPLC2 다가옴(가까움 증가율) · LC 가장자리 · L3 가까움     = 96
  → 하행 뉴런 48  (좌우 20쌍 거울상 + 가운데 8, 같은 쪽 흥분·반대쪽 억제, 세기만 학습)
  → 선형 읽기 → 조향 ±21.4°, 속도
```

- **시뮬 센서:** LiDAR 로 만든 2D 지도의 벽을 33 cm 덕트로 세워 depth 를 계산, 데이터시트 기준 오차(σ = 0.01·d²)·구멍·장착 각도 흔들림 추가.
- **실차 노드:** depth 영상 → 같은 격자 → 회로 → `/drive`, torch 없이 numpy. 시뮬과 실차가 같은 변환 코드를 쓰도록 설계.

## 3. 과정에서 찾은 문제와 해결

**① 처음부터 강화학습 → 10만 스텝에도 첫 코너에서 충돌.** 회로의 부호(극성)를 단계별로 전수 검사하는 도구를 만들었다 (시뮬 장면 11개).

| 단계 | 검사 | 결과 |
|--|--|--|
| 다가옴 (LPLC2) | 정면 장애물로 다가가면 + | **거꾸로 동작** — 2 m 밖 물체는 가장자리가 프레임당 1칸도 안 움직여 '멀어짐'으로 읽힘 → **가까움 증가율**로 직접 계산 (물체의 시각 크기 팽창률과 같은 양) |
| 하행 뉴런 부호 | 왼쪽이 가까우면 왼쪽 뉴런이 켜져야 함 | **랜덤 부호(60:40)였음** → 좌우 대칭 배선. 영상을 좌우로 뒤집으면 짝 뉴런이 정확히 같은 값 |
| 가장자리 (LC) | 좌우 대칭 | 한 칸 어긋남 → 대칭 계산 |
| 좌우 흐름 (HS) | 회전 방향 부호 | 정상. 매끈한 벽을 따라 직진할 때 0 인 것도 정상 (depth 엔 무늬가 없음) |

**② 레이싱라인 모방학습 (DAgger).** 선생님 = 레이싱라인 pure pursuit, 학생 = 실차에 올라갈 회로 그대로.
처음엔 학생이 검증 손실은 낮은데 혼자 몰면 바로 충돌 — **'직전 명령'을 보고 방금 한 행동을 반복하는 것만 배운 것(copycat 문제)**.
모방학습 동안 그 입력을 막자 해결: 출발 8곳 중 5곳이 3바퀴 무사고 완주, 모두 1바퀴 이상.

**③ 모방학습 → 강화학습으로 넘길 때 무너짐.** 학습 중 에피소드가 매번 8초 안에 끝나고 엔트로피 계수가 0.025 → 0.5 로 계속 커짐.
시뮬로 확인하니 행동 잡음 σ 0.2 에서 같은 정책이 226 스텝 만에 충돌(잡음 없으면 481 스텝), 그리고 SAC 의 목표 엔트로피가
모방한 정책보다 높아 무작위성을 계속 키우고 있었음 → 잡음 σ 0.1, 목표 엔트로피 −3.5, 처음 3만 스텝은 critic 만 학습.

**④ 장애물을 피한 뒤 라인 밖에서 코너 진입 시 충돌** → 학습 출발의 절반을 라인에서 벗어난 위치·각도로 (진행 중).

## 4. 현재 상태와 한계

- 결과는 전부 **시뮬레이션**이고, 장애물 회피는 강화학습으로 학습 중이다 (모방학습만으로는 장애물 2개에서 1/8).
- 시뮬 depth 의 오차·구멍은 데이터시트와 추정값 → 카메라 도착 후 실제 덕트를 찍고, LiDAR 를 정답으로 센서 모델을 보정할 계획.
- 고속(7 m/s)에서는 30 fps 자체보다 **브레이크 없음**(타력 감속에 약 11 m 필요, depth 는 7 m 까지)이 문제 → 브레이크 검토.
- 실차 노드는 지연을 줄이기 위해 C++ 로 옮길 예정.
